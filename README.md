# مزه دل بر | رستوران دل بر

سایت منو و سفارش آنلاین رستوران **دل بر** (تک‌صفحه‌ای، فارسی و راست‌به‌چپ).

## امکانات
- منوی دسته‌بندی‌شده (پیش‌غذا، غذای اصلی، نیمه‌آماده، نوشیدنی) با جست‌وجو
- سبد خرید و «سفارش‌های من» (ذخیره در `localStorage` مرورگر)
- تخفیف‌های ویژه با تایمر
- ورود / ثبت‌نام با کد یکبارمصرف
- لینک سفارش از طریق [روبیکا](https://rubika.ir/delbar_mazeh) و [ایتا](https://eitaa.com/Delbar_Mazeh)

## ساختار پروژه
```
.
├── index.html      # کل سایت (HTML + CSS + JS)
├── assets/         # لوگو و عکس‌های غذاها
├── .nojekyll
└── README.md
```

## اجرا روی GitHub Pages
1. ریپو را در GitHub بسازید و فایل‌ها را push کنید.
2. در **Settings → Pages** گزینهٔ **Deploy from a branch** را بزنید، شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب کنید.
3. چند دقیقه بعد سایت در `https://USERNAME.github.io/REPO/` در دسترس است.

## اجرای محلی
```bash
python3 -m http.server 8000
# سپس http://localhost:8000
```

## تنظیمات
- متغیر `OTP_API` داخل `index.html` آدرس سرور ارسال کد تأیید است. خالی بماند، ورود فعال نمی‌شود؛ مقدار `"demo"` حالت آزمایشی است.
- صفحهٔ `learn.html` (دستیار آشپزی) به آن لینک شده ولی در این ریپو نیست؛ اگر دارید کنارِ `index.html` بگذارید.
